# Wrong Turn

## О проекте

Wrong Turn — это учебный веб-сервис для подготовки к теоретическому экзамену по ПДД.  
Проект разработан в рамках учебной практики по модулю ПМ.02 «Осуществление интеграции программных модулей».  
Основная цель — предоставить пользователям возможность тестировать свои знания правил дорожного движения, а администратору — управлять базой вопросов.

## Функционал

- Регистрация и авторизация пользователей с валидацией данных
- Панель администратора для управления вопросами (добавление, редактирование, удаление)
- Импорт вопросов из JSON-файлов
- Поиск и сортировка вопросов в панели администратора
- Режимы тестирования: экзаменационный (20 вопросов, 2 ошибки), обычный (20 вопросов), марафон (все вопросы)
- Аналитика и статистика прохождения тестов
- Адаптивный интерфейс

## Технологии

- Python 3.14, Django 5.0+
- SQLite
- HTML, CSS, JavaScript
- GitHub Actions (CI/CD)

## Юнит-тесты

В проекте реализовано 80 юнит-тестов, вот некооторые из них:

**RegistrationAuthTests **
- Проверка успешной регистрации и входа
- Проверка валидации пароля (длина, заглавные буквы, цифры, спецсимволы)
- Проверка валидации email и логина
- Проверка обязательных полей
- Проверка выхода из системы и контроля доступа

**AdminToolsTests **
- Проверка CRUD операций с вопросами (добавление, редактирование, удаление, просмотр)
- Проверка импорта JSON (валидный, частично валидный, невалидный)
- Проверка разграничения прав доступа (администратор vs обычный пользователь)
- Проверка обработки ошибок (пустой текст, мало вариантов, неверный JSON)

## Установка и запуск

1. Клонировать репозиторий
2. Установить зависимости: pip install -r requirements.txt
3. Применить миграции: python manage.py migrate
4. Создать суперпользователя: python manage.py createsuperuser
5. Запустить сервер: python manage.py runserver

## CI/CD

При каждом push в ветку main автоматически запускаются все 80 юнит-тестов через GitHub Actions.
